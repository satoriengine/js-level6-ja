# JavaScriptレベル6

JavaScript (JS) の基礎的な学習を修了した方に向けて、より発展的な文法を紹介します。

JavaScriptの非同期処理と通信処理を学習します。現代のウェブ開発において、サーバとのデータ通信や時間のかかる処理を効率的に扱う「非同期処理」の理解は不可欠です。まず基本となるコールバック関数の仕組みから学び、処理の順序制御を習得します。

続いて、従来の複雑なコード（コールバック地獄）を解決するために登場したPromise、そして現代の標準であるasync / awaitへとステップアップします。最終的には、fetch APIを用いた通信処理までカバーします。

## 内容
JavaScriptレベル6では以下のテーマを取り扱います。

* コールバック処理の基本
* 非同期処理の基本
* Promiseの利用
* fetchを利用した通信処理
* async / await

「ECMAScript2015」以降に準拠していますが、本カリキュラムでは上記の分野のみを取り扱います。

## 対象
JavaScriptレベル6は以下のような方を対象にしています。

* 初めてプログラミングを学習する方
* JavaScriptの学習が初めての方
